# Exercise 1.42

Let $f$ and $g$ be two one-argument functions. The composition $f$ after $g$ is defined to be the function $x \mapsto f(g(x))$. Define a procedure `compose` that implements composition. For example, if `square` is a procedure that squares its argument,

```scheme
((compose square inc) 6)
; => 49
```

## Solution

```scheme
(define (compose f g)
  (lambda (x) (f (g x))))
```
