# Exercise 2.5

Show that we can represent pairs of nonnegative integers using only numbers and arithmetic operations if we represent the pair $a$ and $b$ as the integer that is the product $2^a3^b$. Give the corresponding definitions of the procedures `cons`, `car`, and `cdr`.

## Solution

```scheme
(define (exp a b)

  (define (even? x)
    (= (remainder x 2) 0))

  (define (sq x)
    (* x x))

  (define (exp-iter res a b)
    (cond
      [(= b 0) res]
      [(even? b) (exp-iter res (sq a) (/ b 2))]
      [else (exp-iter (* res a) a (- b 1))]))

  (exp-iter 1 a b))

(define (cons x y)
  (* (exp 2 x) (exp 3 y)))

(define (car p)

  (define (car-iter res p)
    (if (= (remainder p 2) 0) (car-iter (+ res 1) (/ p 2)) res))

  (car-iter 0 p))

(define (cdr p)

  (define (car-iter res p)
    (if (= (remainder p 3) 0) (car-iter (+ res 1) (/ p 3)) res))

  (car-iter 0 p))
```
